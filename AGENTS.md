Oracle database work must use bin/run-sql.sh.

Before database work:

1. Search engineering history.
2. Search by task description.
3. Search by object names.
4. Search by Oracle errors.
5. Review similar previous runs.
6. Include an INTENT block.
7. Execute through run-sql.sh.
8. Review outcome and logs.
9. Avoid repeating previous failed approaches unless explaining why the new approach differs.

The engineering history exists to provide experience, not merely audit records.
