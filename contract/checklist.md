# GSC conformance checklist: the road-kit todo demo

The 35 items of the gsc skill's checklist (`gsc/skills/governed-surface-contract/references/checklist.md`),
checked against road-kit's reference surface: `contract/hello_world.gsc.json` (contract 0.1.0) with the
framework fragments `road-agents` and `road-session`. 6 actions and 2 views of its own, plus 4 actions
and 2 views from the fragments. Written for spec-patch-16 and updated whenever the surface changes.

**Status as of 15 November 2026.** Built and tested on `ROAD_KIT_DEV`. The demo is small on purpose: it
shows each part of a governed surface once, so items about parts it does not use say so.

| Status | Meaning |
|---|---|
| Pass | Shown, with the evidence given |
| Declared | Required by the contract and checked there, but not yet shown running |
| Not yet | Neither declared nor built; what would build it is named |
| Not used | Does not apply to this surface |

Tests named below: `demo_todo_api_test` (PL/SQL, 19), `road_surface_api_test` (PL/SQL, 8),
`road_agent_api_test` (PL/SQL, 8), `test/agents/surface.test.mjs` (HTTP, 26), `agents.test.mjs` (HTTP, 19),
`road-cli.test.mjs` (15). The HTTP and CLI ones run with `bin/run-agent-tests.sh --env dev`; the PL/SQL
ones with `bin/run-sql.sh --env dev --script test/plsql/run-framework-tests.sql`.

| 1 | One contract, one version, one metadata format | Pass | `contract/hello_world.gsc.json` plus its fragments, merged by `scripts/lib/contract-merge.mjs`, validated by `scripts/validate-gsc-contract.mjs` against schema 0.3.0; one document served at `GET /contract/` |
| 2 | Identity only from the authenticated context | Pass | Every handler on a protected module calls `road_ctx_pkg.begin_request(:current_user)` (`bin/check-handler-coverage.sh`); the owner of a todo is the caller, and a body that names one is a 400 (`test_create_refuses_a_named_owner`, `surface.test.mjs`) |

| 5 | Every response states the contract version; discoverable | Pass | Outcomes, views, and 400, 401, 403 and 404 bodies carry `contract_version` (`surface.test.mjs`); `GET /contract/` is public and serves the document; another major `Accept-Version` is a 400 `VERSION_MISMATCH` |
| 6 | Business rejections 200, wrong calls 4xx, failures 5xx | Pass | Rules answer 200 with `rule_id` and `audit_id`; a missing key, a missing token and a named owner are 400; a missing permission is 403; a hidden or deleted todo is a 404 on a view (`surface.test.mjs`). 5xx goes through `road_surface_api.fail`; no test forces one |

## B. Governed state contract

| # | Item | Status | Evidence |
|---|---|---|---|
| 8 | No generic update; one business operation per call | Pass | Six named actions, none a generic update. `todos.revise` changes only title, notes and due time; complete, reopen and delete are their own actions |
| 9 | Action resources are nouns | Pass | `/todos/{id}/revisions/`, `/completions/`, `/reopenings/`, `/todos/purges/`, `DELETE /todos/{id}/`, `/agents/{id}/keys/`; trailing slash, at most two levels. Checked by reading, not by a script |
| 10 | Consumers cannot set derived fields | Pass | Owner from the session; status changes only through complete, reopen and delete; `updated_at` is trigger-maintained |
| 11 | Every action declares the twelve parts | Pass | Schema 0.3.0 requires them; the contract validates |
| 12 | Every precondition has id, description and kind | Pass | Schema. The demo has no rule catalogue (road-tracker has `contract/rule-catalogue.json`), so kinds are not checked against one |
| 13 | No business rules in binding code | Pass | Handlers are generated by `scripts/generate-modules.mjs` from `api/routes.mjs`: session, version, one package call, respond. `--check` fails if a file was edited by hand |
| 14 | Re-read, test and apply in one transaction | Pass | `demo_todo_api.decide` locks and re-reads the todo after a savepoint; `test_stale_token_leaves_no_change` |
| 15 | Outcome shape | Pass | `road_decision_api` through `road_surface_api`; PL/SQL and HTTP tests check `decision`, `audit_id`, `rule_id`, `retryable` and ids |
| 16 | Non-disclosing rejections declared | Pass | None used: `TODO_NOT_FOUND` is refused openly, with no ids, and answers alike for a hidden, deleted and missing todo (`test_other_owners_todo_is_not_found`, `surface.test.mjs`) |
| 17 | Every action idempotent | Pass | Same Idempotency-Key replays a create (`test_create_replays_by_key`, HTTP); same token and todo replays a complete or revise (`test_same_token_same_todo_replays`, HTTP). Delete and reopen share `decide`; purge shares the key path |
| 18 | Changes to existing records check a read token; stale is retryable | Pass | `test_stale_token_leaves_no_change`; HTTP: a token from before a change is `STALE_TOKEN`, retryable, and nothing changes |
| 19 | Locks, claims and leases declared | Not used | The demo has none; road-tracker's claims are the worked example |
| 20 | Accepted audited in the transaction; rejected survives rollback | Pass | `road_decisions`; `road_decision_api_test` (`test_accept_rolls_back_with_caller`, `test_reject_survives_rollback`); the stale test reads the refusal after the rollback |
| 21 | Events recorded in the transaction, delivered after commit | Not used | `events.emitted` is empty on every action: road-kit has no event outbox yet (road-atlas RK-12) |
| 22 | Batches | Not used | No `state.batch`; spec-patch-14 is not ruled |
